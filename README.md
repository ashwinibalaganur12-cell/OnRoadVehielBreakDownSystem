# On-Road Vehicle Breakdown System

A web-based application designed to connect stranded vehicles and travelers with nearby mechanics, service centers, and emergency breakdown assistance.

## 🚀 Features
- **User Module:** Request emergency roadside assistance, view nearby mechanics, and track service status.
- **Mechanic & Admin Module:** Manage incoming service requests, update task status, and manage service locations.

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript, React.js
- **Backend:** PHP / RESTful API
- **Database:** MySQL
